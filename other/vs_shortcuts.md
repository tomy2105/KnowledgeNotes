Ctrl+D - duplicate line
Ctrl+Shift+L - delete a line
Alt while making a selection - box/vertical selection with multiple cursors
Ctrl+Shift+left/right/up/down/end - box selection with multiple cursors
Alt+Ctrl+click - multiple cursors at multiple locations
Alt+Shift+. - repeatedly to select all instances of the word a cursors is currently on with multiple cursors
Alt+Shift+; - select all instances of the word a cursors is currently on with multiple cursors
Ctrl+left/right - move next/previous word
Alt+Ctrl+left/right - move next/previous subword (next capital letter)
Ctrl+Shift+F - find in files
